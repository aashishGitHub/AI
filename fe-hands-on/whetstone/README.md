# Whetstone — Senior / Lead / Principal Frontend Interview Notes

Own-words study notes built from [whetstone-v1.vercel.app](https://whetstone-v1.vercel.app/)
(source: [anand1296/whetstone](https://github.com/anand1296/whetstone)). 112 questions, 15 rounds, ~32 h of study.

**Method (from the site):** read the question, answer out loud, then open the note and compare.
Re-review done questions after 2, 5, 12, 30 and 75 days.

## Rules
- Proof points: LCP 22s+ → 6–7s · ~25% CS cost cut · ~$100K/month saved · handling time 2 min → 40 s. No other numbers.
- AWS SA-Associate = "in preparation" until passed.
- Every study block ends in an artifact: code, write-up or scored mock.
- No AI tools in real interview rounds unless the round provides one.
